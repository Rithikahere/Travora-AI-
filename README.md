# 🌍 Travora AI

AI-powered travel itinerary planner built with React, Express.js, Groq AI, and the Unsplash API.

---

## 📖 About the Project

This project was developed as part of a frontend development assignment to build a production-ready AI travel itinerary planner. The application enables users to generate personalised travel itineraries from natural language prompts while integrating the Groq API for AI-generated travel plans and the Unsplash API for destination and activity images. The project demonstrates full-stack web development, REST API integration, responsive UI design, error handling, and AI-powered content generation.

---

## ✨ Features

- AI-generated travel itineraries
- Personalised travel recommendations
- Destination cover images
- Activity-specific images
- Responsive user interface
- Fast performance with Vite
- Smooth animations using Framer Motion
- Loading and error handling
- JSON response validation
- Clean and modern user interface

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Rithikahere/Travora-AI-.git
```

### 2. Navigate to the Project

```bash
cd Travora-AI-
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
npm run dev
```

### 4. Install Backend Dependencies

```bash
cd ../server
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **server** folder and add the following:

```env
GROQ_API_KEY=your_groq_api_key
UNSPLASH_ACCESS_KEY=your_unsplash_access_key
```
